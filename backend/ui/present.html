How it works

Four moves.

Given an inbound report, Bob runs the same loop a careful maintainer would — only faster, and with the receipts.

01

Parse

Read the report as untrusted input. Extract every claim.

02

Verify

Three subagents in parallel: existence, reachability, prior art.

03

Reproduce

Real issues get a failing test, offline, in a disposable sandbox.

04

Patch

Minimal fix + regression test + a PR the human reviews in minutes.
